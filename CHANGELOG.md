# Changelog

## 3.1.0 — Final Feature Release

- Added compact monitoring for three storage volumes.
- Added per-volume labels, mount paths, and optional SMART device mappings.
- Added SMART temperatures to the storage page.
- Expanded the temperature page to support CPU, selected sensor groups, and
  configured drives.
- Added TUI controls for network interface, storage devices, temperature
  sources, sensor groups, pages, and screensavers.
- Added Pong, Starfield, Matrix Rain, and Radar screensavers.
- Retained Snake and Bouncing Text screensavers.
- Added page plugin architecture and per-page refresh intervals.
- Added Unix-socket notifications and the `polywell-c500-notify` command.
- Documented the verified BIOS password and front-panel protocol.
- Preserved the verified `ESC[2K` runtime row-clear sequence.
